# Change Log

All notable changes to the "light-colors-theme" extension will be documented in this file.

## [1.2.0] - 2025-05-31

### Added
- VS Code 1.78+ support with new theme keys (sticky scroll, inline parameters, chat, ports)
- `editorActiveLineNumber.foreground` color override
- `sash.hoverBorder`, `tab.lastPinnedBorder`, `titleBar.border` for better UI polish
- `statusBar.border` and status bar item state colors (error, warning)
- MIT License, `.vscodeignore`, `.gitignore`
- Gallery banner configuration for marketplace
- Expanded keywords and better marketplace metadata

### Fixed
- Removed duplicate `string` token color rule
- Uncommented and applied `editorActiveLineNumber.foreground`

### Changed
- Editor cursor color from pure `#000000` to softer `#1a1a1a`
- Updated VS Code engine requirement to `^1.78.0`
- Polished documentation with installation guide, color table, and language support list

## [1.1.1] - 2025-03-15

### Added
- Bracket pair highlight colors (6 levels)
- Bracket pair guide colors (6 levels)
- Extensive language token support for 30+ languages

### Fixed
- Various token scope refinements

## [1.0.0] - 2025-01-10

### Added
- Initial release of Material Light Theme
- Light color theme inspired by Material Design
- 270+ workbench color overrides
- 100+ TextMate token scope rules
- Color palette screenshot and code preview
